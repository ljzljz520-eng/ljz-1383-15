# 志愿服务地图 · 隐私粒度设计与验收说明

## 1. 三种公开空间表示的辨识度 vs 可推断风险

| 方案 | 展示辨识度 | 可推断（再识别）风险 | 结论 |
|---|---|---|---|
| **城市质心**（city centroid） | 高：一眼看出“在哪座城市”，城市间完全可分 | 低：同城所有经历落到同一点，点是公共行政坐标，与当事人/机构无个体关联，无法据图钉反推街道 | **默认采用**。辨识度与风险最平衡 |
| **行政区域面**（district/city polygon） | 中高：能表达“在某市/区范围内”，轮廓有地理认知 | 中：区/街道级面边界本身会缩小落点区域；若叠加年份+事件类型，小区域内可推断“某人在某机构”。面数据还可能让人误以为“点在面内某处” | 仅保留**城市级面**能力（数据结构支持 `polygon`），不发布区县级以下面；默认不渲染面、只用质心 |
| **模糊网格**（≈11km geohash 风格吸附） | 中：可表达“城市的哪个方向/片区”，同城多点可区分 | 中高：网格中心 + 事件密度会暴露活动片区；网格越小越接近精确点。与“年+角色”等属性组合时，稀疏区域可被锁定到少数机构 | 作为**可选更粗/可调档**：管理员可切换，单元大小服务端固定（默认 0.1°≈11km），不允许前端自行调小 |

**选定粒度（分层）：**
- 机构在事件发生日期持有**有效公开授权** → 发布机构授权公开点（`org_point`，机构自报坐标，非私有 raw）；
- 否则 → 默认**城市质心**；策略切换后可使用**模糊网格**（11km，服务端吸附）；
- 任何情况下都不发布：原始定位、事件级钉点、机构精确原址、EXIF/GPS、授权时间窗等私有信息。

关键原则：**脱敏在发布前于服务端完成，前端不参与**。前端拿到的就只有公开表示，“把图钉在前端移远”无法满足要求（接口仍会泄漏）。

## 2. 数据三域与有效期

- `raw` 域：事件实际地点、机构各版本精确坐标（WGS84）、照片原图——仅管理端与私有文件区；
- `city` 域：城市编码、名称、质心、可选城市面——公开安全；
- `org-public` 域：机构授权公开名 + 公开点，带 `validFrom/validUntil` 有效期。

机构名称、地点都是**按有效期生效的版本切片**；事件只引用 `orgId + date`，
读取时用 `nameAsOf/locationAsOf(date)` 解析：
- **更名**：只影响生效日后的经历显示；历史经历保留旧称。更名不吊销快照（这是正确语义）；
- **搬迁**：新增地点版本，旧版本继续覆盖历史日期；新事件用新址。搬迁立即吊销已发布快照；
- **授权撤销/过期**：撤销日之后的经历不再发布机构点，回落到城市/网格；撤销立即吊销已发布快照，
  旧分享链接返回 `410 Gone`，必须重新发布。

## 3. 发布快照（地图与统计的唯一公开数据源）

- 发布动作生成内容寻址快照（canonical JSON SHA-256），公开接口、搜索、导出全部只读快照；
- 访客分享 `?snapshot=<id>&year=2024&view=list`：快照不可变，年份/视图是纯客户端参数；
- 时数统计在快照构建时**按原始事件 id 去重**：一个事件即使关联多个公开位置（如机构点+城市聚合），
  也只累计一次；同一服务日的两条不同事件记录（不同 id）各自合法计入；
- 搜索缓存键 = `vmap:<snapshotId>:<归一化参数哈希>`。位置修订 → 新快照 id → 旧缓存键天然不命中，
  不依赖逐个 key 失效；管理端修订时也会清空内存缓存做双保险。

## 4. 隐私泄漏面的收敛（逐条对照需求）

- **接口**：`/api/public/*` 只投影白名单字段；`raw/pinnedRaw/authorizations/publicPoint/validUntil` 永不出现；
- **搜索边界**：不提供点选/半径接口；bbox 最小面积 0.04 经纬度²（约 500km²），并吸附 0.05° 网格，
  防止画小框套出精确点；关键词搜索要求 ≥2 字符或精确城市编码；
- **照片 EXIF**：服务端上传即剥离（JPEG 去 APPn、PNG 去 eXIf/iTXt、WebP 去 EXIF/XMP/ICCP），
  原图只存私有区；媒体接口对任何残留元数据的派生图返回 409；支持从私有原图**重处理**，
  保证“旧派生图混入元数据”也能修复（幂等，重复清洗不复活元数据）；
- **导出文件**：GeoJSON/CSV 只含公开表示坐标与粒度标签，经测试断言不含任何种子精确点；
  旧快照导出同样 410；
- **坐标换算**：WGS84(GPS/相机) 与 GCJ-02(国内底图) 统一经 `shared/geo.mjs` 换算，
  国内偏移约 500–600m，往返误差 <10cm；境外点不加偏；
- **私有文件**：`data/private/` 被静态服务直接 403，且加入 `.gitignore`。

## 5. 地图服务失效降级

- Leaflet CDN 未加载 / 连续 4 个瓦片错误 / 4 秒内零图块加载 → 切换纯 SVG 离线示意图；
- 示意图用公开点做相对排布（等距圆柱投影），不是精确底图，无法放大套点；
- 数据仍来自同一发布快照，列表视图完全不依赖地图服务。
